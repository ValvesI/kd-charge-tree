# kd-charge-tree
Este repositório tem como objetivo apresentar uma simples ideia que tive ao tentar encontrar opções melhores a KD trees para sistemas de fluxo de dado. Em grande maioria, as ideias e linhas de pensamento tomadas foram próprias (com excessão claro da ideia de divisão de eixo espacial da kd tree) portanto referencias para artigos similares ficam ausentes e similarmente não garanto e nem confirmo que a ideia apresentada seja original. Há também a presença de algumas definições feitas para comparações com metódos descobertos posteriormente a implementação da ideia. Códigos e implementações especificas não estão presentes atualmente. Boa parte escrita foi feita com auxilio de inteligência artificial (Chatgpt 6 Astra)
