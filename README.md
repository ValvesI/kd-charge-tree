# KD Charge Tree

This repository presents a simple idea that emerged while exploring alternatives to KD-trees for data-stream systems.

Most of the concepts and lines of reasoning documented here were developed independently, with the obvious exception of the axis-based spatial partitioning inherited from KD-trees. References to related work are currently limited, so this repository neither claims nor confirms that the proposed idea is original.

Some definitions were introduced after the initial implementation to make comparisons with methods discovered later. The current focus of the repository is conceptual: specific implementations and source code are not included yet.

A significant part of the written material was developed with the assistance of artificial intelligence (ChatGPT 6 Astra).
